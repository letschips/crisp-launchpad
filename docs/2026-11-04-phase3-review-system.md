# 第三期（0.8.0）：复盘页节奏与系统问题清单

2026-11-04 作者批准。

## 范围

1. **复盘页节奏改读 Pulse**：去掉按文件修改时间画的 53 周热力图、日明细和「更新日期占比」统计（这些是文件被改动的次数，不是贡献；当天文件明细 Pulse 的日明细已有）。改为「近期节奏」卡片，读 Crisp Pulse 1.42.0 新增的只读接口 `getRecentDays(days)`：
   - 分段控件 7 / 30 / 90 天，柱高是每天的贡献分；没有记录的日子画成虚的、不当成 0。
   - 汇总：有产出天数 / 有记录天数、连续天数、专注时长、完成任务数。
   - 「在 Pulse 看复盘」打开 Pulse 看板。
   - 没有 Pulse 或 Pulse 太旧时只显示一句提示，不画假数据。
2. **系统问题清单按类型归组**：110 条实际只有 8 种。每组一行：中文名、级别、数量；阻塞组默认展开，其余点开再看；组内每行只写文件名和所在目录（不再把路径重复两遍），窄面板不换行成多行。
   - 有去处的组带处理入口：超过 3 天未整理 → 知识页待整理；待回写 → 复盘页；在制内容过多 → 创作页。
   - 排序：阻塞 → 待办 → 提示，同级按数量从多到少。未知代码显示原代码，不丢。

## 不做

不改 ANKS health 的规则；不新增设置；不自动删除孤立附件。

## 回归用例

- 复盘页不再出现旧热力图；有 Pulse 时柱数等于所选天数，未记录日为虚柱，汇总数字与接口数据一致；切换 7/30/90 天柱数跟着变。
- 没有 Pulse 或没有 `getRecentDays` 时显示提示，不抛异常。
- 系统页分组数等于不同代码数；阻塞组在最前且默认展开；已知代码显示中文；组头数量正确；超过 3 天未整理组的入口跳到知识页。

## 验收

Launchpad `npm run check`、`npm run test:e2e`；Pulse 测试；ANKS 后台核对（不切作者的标签）；发布 Launchpad 0.8.0、Pulse 1.42.0。
